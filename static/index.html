Can four numbers tell real money from fake?

Mintmark is a logistic regression trained on about 1,370 banknote images. Give it four measurements taken from a note’s picture and it returns a verdict: genuine or forged, with a probability.

How it decides

The four numbers

Each note was photographed, and four values were calculated from the picture. Variance is how spread out the pixel values are. Skewness is how lopsided they are. Kurtosis is how extreme the rare bright or dark spots are. Entropy is how random the image is.

Forgeries are usually printed differently, which shows up in these statistics.

Putting them on one scale

The four numbers live on different scales, so each one is converted to “how many standard deviations from average”. The average and spread come from the training notes only, never the test notes, so nothing leaks from the exam into the study session.

From a score to a probability

The model gives each number a weight and adds them into one score. The sigmoid curve then squeezes any score into a probability between 0 and 1. A score of 0 means 50%. Drag the slider to see it.

An honest exam

The data was split 80/20, keeping the same share of forgeries in both parts. The model never saw the 275 test notes while learning, so the scores below show how it handles notes it has not met.

Run it yourself

The page is served by a small FastAPI app that loads the saved model and exposes one prediction endpoint.

python -m pip install fastapi "uvicorn[standard]"
python -m uvicorn main:app --reload
# then open http://127.0.0.1:8000/
Mintmark is a learning project built on a public dataset. The note artwork is an original specimen, not any real currency, and the model is not for real cash handling.
